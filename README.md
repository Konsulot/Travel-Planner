# Travel Planner

Travel Planner — клиентское Android-приложение на Kotlin для планирования путешествий. Создание поездок и маршрутов, управление местами и событиями, учёт бюджета и расходов, конвертация валют, список вещей и статистика поездки.

## Цель проекта

Помочь путешественникам планировать поездки в одном месте: от подбора мест и составления маршрута до контроля бюджета и расходов прямо во время поездки. Приложение работает офлайн и хранит данные локально на устройстве (интернет нужен только для обновления курсов валют).

## Возможности

- ✅ создание, редактирование, удаление и просмотр поездок;
- ✅ указание места назначения, дат и бюджета в выбранной валюте;
- ✅ просмотр деталей поездки (вкладки «Обзор», «Расходы», «Маршрут», «Места», «Вещи», «Статистика»);
- ✅ добавление, редактирование и удаление расходов по категориям;
- ✅ расчёт потраченного и оставшегося бюджета, процент использования, предупреждение о перерасходе, рекомендуемый лимит трат в день;
- ✅ расходы в любой валюте — автоматически пересчитываются в валюту бюджета поездки;
- ✅ маршрут и события по дням (время, место, отметка «выполнено»);
- ✅ места и wishlist (фильтры, отметка «посещено», открытие адреса в картах);
- ✅ список вещей для сборов с категориями, количеством и базовым шаблоном;
- ✅ конвертация валют по актуальным курсам (open.er-api.com) с кешированием для офлайна;
- ✅ статистика и графики: кольцевая диаграмма по категориям, столбчатая — по дням;
- ✅ пример поездки одним нажатием (удобно для демонстрации);
- ✅ светлая и тёмная тема.

## Стек и архитектура

- **Язык:** Kotlin 2.0
- **UI:** Jetpack Compose + Material Design 3, Navigation Compose
- **Данные:** Room (SQLite) — поездки, расходы, события, места, вещи, кеш курсов валют
- **Валюты:** API курсов [open.er-api.com](https://open.er-api.com/v6/latest/USD) (бесплатный, без ключа)
- **Асинхронность:** Kotlin Coroutines + Flow
- **Архитектура:** MVVM — UI (Compose) → ViewModel (StateFlow) → Repository → Room / сеть
- **DI:** ручной контейнер зависимостей (`AppContainer`)
- **Графики:** собственные Compose-компоненты на Canvas, без сторонних библиотек

```
Compose-экран ──события──▶ ViewModel ──▶ Repository ──▶ Room DAO ──▶ SQLite
      ▲                       │              │
      └──── StateFlow ◀───────┘              └──▶ ExchangeRateApi (HTTP, курсы валют)
```

## Модель данных

| Таблица          | Назначение                                                           |
|------------------|----------------------------------------------------------------------|
| `trips`          | Поездка: название, место, даты, бюджет, валюта, заметки              |
| `expenses`       | Расход: сумма и валюта, сумма в валюте поездки, категория, дата      |
| `events`         | Событие маршрута: день, время, место, отметка выполнения             |
| `places`         | Место: адрес, заметка, wishlist, посещено                            |
| `packing_items`  | Вещь: категория, количество, собрано                                 |
| `currency_rates` | Кеш курсов валют относительно USD                                    |

Дочерние таблицы связаны с `trips` внешним ключом с `ON DELETE CASCADE` — при удалении поездки удаляется всё, что к ней относится.

## Запуск

1. Открыть проект в Android Studio (Koala 2024.1.1 или новее).
2. Выполнить Gradle Sync.
3. Запустить конфигурацию `app` на эмуляторе или устройстве с Android 8.0+ (API 26).

Сборка из командной строки:

```bash
./gradlew assembleDebug
```

## Тесты

```bash
./gradlew test                  # unit-тесты (JVM)
./gradlew connectedAndroidTest  # тесты Room и UI (нужен эмулятор или устройство)
```

- **Unit-тесты:** расчёт бюджета и дневного лимита, конвертация валют, статистика, форматирование, валидация форм, шаблон вещей, репозиторий курсов (обновление, офлайн-режим, разбор JSON), ViewModel создания/редактирования поездки, деталей поездки и конвертера.
- **Интеграционные тесты:** Room в памяти — сохранение, суммирование расходов, каскадное удаление, порядок событий, пересчёт валюты.
- **UI-тесты:** список поездок (пустое состояние, карточка, переход), форма поездки (ошибки валидации, ввод, сохранение).
