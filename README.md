# Travel-Planner

Travel Planner - клиентское Android-приложение на Kotlin для планирования путешествий. Создание поездок и маршрутов, управление местами и событиями, учёт бюджета и расходов, конвертация валют, список вещей и статистика поездки.

## Цель проекта

Помочь путешественникам планировать поездки в одном месте: от подбора мест и составления маршрута до контроля бюджета и расходов прямо во время поездки. Приложение работает офлайн и хранит данные локально на устройстве.

## Возможности

- создание и просмотр поездок;
- указание места и бюджета;
- просмотр деталей поездки;
- добавление расходов;
- расчёт потраченного и оставшегося бюджета;
- маршрут и события по дням (в плане);
- список вещей для сборов (в плане);
- конвертация валют по актуальным курсам (в плане);
- статистика и графики по поездке (в плане).

## Стек

- Kotlin
- Android
- Jetpack Compose
- Material Design 3

## Стек и архитектура

- **UI**: Jetpack Compose + Material Design 3, навигация по экранам.
- **Данные**: локальная Room-база данных для сущностей поездок и расходов.
- **Валюты**: сторонний API курсов для конвертации.
- **Архитектура**: MVVM (UI + ViewModel + Repository + данные).

## Структура проекта

Ожидаемая структура будущего кода приложения:

```
app/
├── src/main/java/com/travelplanner/
│   ├── ui/                 # UI-экранный и навигация
│   │   ├── screens/        # Экраны (список поездок, детали, расходы)
│   │   └── components/     # Переиспользуемые Compose-компоненты
│   ├── data/               # Room, DAO, Repository
│   ├── model/              # Модели данных
│   └── util/               # Утилиты (валюты, форматирование)
└── src/main/res/           # Ресурсы (drawable, strings, themes)
```
