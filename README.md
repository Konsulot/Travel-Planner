# Travel-Planner
Travel Planner - клиентское Android-приложение на Kotlin для планирования путешествий. Создание поездок и маршрутов, управление местами и событиями, учёт бюджета и расходов, конвертация валют, список вещей и статистика поездки.

# Возможности
- создание и просмотр поездок;
- указание места и бюджета;
- просмотр деталей поездки;
- добавление расходов;
- расчёт потраченного и оставшегося бюджета

# Стек
- Kotlin
- Android
- Jetpack Compose

# План развития
- календарь и маршрут по дням;
- места и wishlist;
- API курсов валют;
- список вещей;
- статистика и графики;
- полноценная Room-база данных;
- UI и integration tests.

# Запуск
Открыть проект в Android Studio и выполнить Gradle Sync.
