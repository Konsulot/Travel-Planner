Агент: Твой проект — **Travel Planner**: Android-приложение на Kotlin + Jetpack Compose для планирования путешествий.

**Основные возможности:**
- Создание поездок с бюджетом, датами, валютой
- Учёт расходов по категориям с автоконвертацией валют (офлайн-кеш курсов)
- Маршрут по дням (события с временем, отметка «выполнено»)
- Места и wishlist (фильтры, открытие в картах)
- Список вещей для сборов с категориями и количеством
- Статистика: диаграммы по категориям и дням
- Пример поездки для демо, светлая/тёмная тема

**Стек:** Kotlin 2.0, Compose + Material 3, Room (SQLite), Coroutines + Flow, MVVM, ручной DI, графики на Canvas.

**Текущий бюджет в travel.json:** 45 000 ₽, уже внесено 3 расхода (транспорт, жильё, другое) на сумму 23 200 ₽.

**Планы развития** (из TODO.md): синхронизация между устройствами, уведомления о событиях, карта с местами.
