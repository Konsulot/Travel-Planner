# Возможности Travel Planner

Travel Planner — Android-приложение для планирования путешествий. Работает офлайн, все данные хранятся локально на устройстве в базе Room. Интернет нужен только для обновления курсов валют.

## Список поездок

На главном экране поездки разделены на две группы: «Текущие и предстоящие» (по дате начала) и «Завершённые» (сначала самые свежие). На карточке поездки видны название, место, даты, длительность и полоска бюджета: «Потрачено X из Y».

У каждой поездки есть статус: «Через N дней» или «Завтра» до начала, «В пути · день 2 из 5» во время поездки и «Завершена» после окончания.

## Создание поездки

При создании указываются название, место назначения, даты начала и окончания, бюджет, валюта бюджета и заметки. Обязательны все поля, кроме заметок. Дата окончания не может быть раньше даты начала. Бюджет может быть нулевым, но не отрицательным. Валюта по умолчанию — RUB.

После создания приложение сразу открывает экран поездки.

## Экран поездки

Экран поездки состоит из шести вкладок:

- «Обзор» — даты, статус, карточка бюджета, ближайшие планы, прогресс по вещам и местам;
- «Расходы» — траты по дням с итогом за день;
- «Маршрут» — события по дням поездки;
- «Места» — места для посещения и wishlist;
- «Вещи» — список сборов;
- «Статистика» — графики расходов.

## Статистика

Вкладка «Статистика» показывает общую сумму трат, количество расходов, средний расход в день, сумму трат до начала поездки и самую крупную трату. Кольцевая диаграмма показывает доли категорий, столбчатая — траты по дням. Цветом выделяются дни, когда траты превысили план: бюджет, делённый на число дней поездки.
