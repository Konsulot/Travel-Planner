# Конвертер валют

## Откуда берутся курсы

Курсы загружаются из бесплатного API open.er-api.com (ExchangeRate-API, без ключа). Базовая валюта — доллар США: для каждой валюты хранится, сколько её единиц стоит 1 USD. Конвертация идёт через доллар: сумма / курс(из) × курс(в).

Загруженные курсы сохраняются в базе, поэтому конвертер работает без интернета. Приложение обновляет курсы автоматически, если они старше 12 часов. Обновить вручную можно кнопкой «Обновить» на экране конвертера.

## Офлайн-курсы

Если курсы ещё ни разу не загружались, используются встроенные примерные курсы. Тогда на экране конвертера показывается предупреждение «Используются примерные офлайн-курсы», а при вводе расхода рядом с пересчётом пишется «(примерный курс)».

## Доступные валюты

В приложении 24 валюты: RUB, USD, EUR, GBP, CNY, JPY, TRY, AED, THB, GEL, AMD, KZT, BYN, UZS, KGS, AZN, CHF, CZK, PLN, EGP, INR, VND, IDR, KRW.

## Быстрый пересчёт

Под результатом конвертер показывает ту же сумму в популярных валютах: RUB, USD, EUR, CNY, TRY, GEL, AED, THB (кроме двух уже выбранных).
